The pinned CPython [3.12.10 callproc.c](https://github.com/python/cpython/blob/v3.12.10/Modules/_ctypes/callproc.c#L1292) replaces ERROR_MOD_NOT_FOUND with a formatted FileNotFoundError, omitting the native error code. The previous control required error.winerror == 126 and reraised this intended failure. The fix uses typed [LoadLibraryExW](https://learn.microsoft.com/en-us/windows/win32/api/libloaderapi/nf-libloaderapi-loadlibraryexw) and reads the original Win32 code immediately. It still rejects every unexpected loader result; no model or runtime behavior changes.
