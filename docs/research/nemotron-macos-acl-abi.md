# Darwin extended-security attribute ABI audit

2026-10-17; source-only, no `getattrlistat`, scratch control, helper, VM, mount or permission operation executed. This audits [the proposed metadata parser](../../tools/nemotron-diarization/macos_vm_permissions_probe.py), not access policy or ACL absence. Actual selected headers/manual below are from **Xcode26.5**, rather than the earlier CLT SDK. Published XNU `f6217f891ac0bb64f3d375211650a4c1ff8ca1ea` supplies implementation evidence; it is not asserted to be the exact host26.3 kernel binary.

## Layout supported by headers/manual

The [actual attr.h](</Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX.sdk/usr/include/sys/attr.h>) defines `attrlist` as two16-bit fields plus five32-bit bitmaps:24bytes; `bitmapcount=5`, `commonattr=0x00400000` selects only extended security, and `FSOPT_NOFOLLOW=1`. `attrreference_t` is signed32-bit offset plus unsigned32-bit length. The [manual](</Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX.sdk/usr/share/man/man2/getattrlist.2>) specifies four-byte alignment and offsets relative to the reference itself. Thus the one-attribute result has a4-byte total length followed by an8-byte reference; payload starts at `4+offset`, not `offset`. `getattrlistat` anchors a relative leaf to the supplied parent directory.

The [actual kauth.h](</Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX.sdk/usr/include/sys/kauth.h>) and included16-byte `guid_t` imply a36-byte filesec prefix, followed by count/flags at offsets36/40: **44+24×count** bytes, maximum128ACE entries. Magic is `0x012cc16d`; `0xffffffff` is `KAUTH_FILESEC_NOACL`, requiring no ACE array. **Count0 and count0xffffffff are distinct**, although both occupy44bytes. The manual says only the ACL portion is used; owner/group fields cannot establish guest ownership. On admitted native little-endian arm64, little-endian decoding matches the source's native struct copying; this is not a portable on-disk-xattr parser.

## Empty and unavailable are not equivalent

[XNU packing](https://github.com/apple-oss-distributions/xnu/blob/f6217f891ac0bb64f3d375211650a4c1ff8ca1ea/bsd/vfs/vfs_attrlist.c#L1945-L1958) creates a filesec prefix plus ACL when `va_acl` is supported and nonnull. Otherwise, without returned-attribute reporting, it packs a zero-length variable attribute. [The variable packer](https://github.com/apple-oss-distributions/xnu/blob/f6217f891ac0bb64f3d375211650a4c1ff8ca1ea/bsd/vfs/vfs_attrlist.c#L171-L220) computes the offset even for length0: the ordinary one-attribute shape is **total12, offset8, length0**, whose payload start equals buffer end. This path covers unsupported/null ACL data; it cannot alone certify ACL absence. A44-byte NOACL sentinel and an empty ACL are separate representations.

The parser's accepted `offset0,length0` special case may be retained as **raw unknown**, but is not this implementation's canonical zero-length packing. Do not dereference it, call it a recognized filesec, or infer empty/no ACL. Its existing `acl_policy_qualified=false` is essential. Source checks and syscall success do not establish filesystem support or an access verdict.

## Bounds and malformed responses

The manual warns of silent truncation and references pointing beyond the copied buffer. Without `FSOPT_REPORT_FULLSIZE`, the leading size can describe only copied bytes; `size==len(raw)` alone does not prove completeness. For this fixed request, validate the entire reference, including **zero-length references**: nonnegative/aligned offset, start at/after fixed end, `start<=size`, and `length<=size-start`. A start exactly at end is valid only with length0. Reject overflow, partial headers/references and any recognized filesec whose exact length/count exceeds bounds; distinguish short/unknown magic as opaque rather than recognized. The largest declared full result is3128bytes, well below64KiB. Adding returned-attribute/full-size options later changes interpretation and must be separately frozen. [Manual truncation contract](</Applications/Xcode.app/Contents/Developer/Platforms/MacOSX.platform/Developer/SDKs/MacOSX.sdk/usr/share/man/man2/getattrlist.2>).

Preserve raw bytes/digest, return/errno, parser classification and requested options. A future host scratch control can verify the actual ABI path, but cannot promote an opaque zero-byte attribute to a guest ACL claim. No runtime/protocol/parser edits were made here.
