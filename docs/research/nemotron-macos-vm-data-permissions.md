## Inspect before choosing a change

Walk only the already-admitted mount and literal components, retaining the accessible `Default` parent descriptor. Use `fstatat(parent_fd,"users",…,AT_SYMLINK_NOFOLLOW)`—Python's `os.stat("users",dir_fd=parent_fd,follow_symlinks=False)` counterpart—to inspect the entry **before opening it**. Record type, full mode, inode/device, link count, flags, size and timestamps; apparent UID/GID remain non-authoritative under noowners. Reject symlinks, filesystem crossings and changed identity. If an earlier component fails, record its parent-relative metadata instead of guessing. [SDK stat manual](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/share/man/man2/stat.2>).

For ACL metadata without reading directory contents, Darwin documents `getattrlistat(parent_fd,"users",…,FSOPT_NOFOLLOW)` and `ATTR_CMN_EXTENDED_SECURITY` (variable-length `kauth_filesec` ACL). Bound the buffer, validate returned lengths, retain ACL metadata/digest and errors; denied or unsupported security metadata is not an empty ACL. Do not read account records. [SDK getattrlist manual](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/share/man/man2/getattrlist.2>), [attribute definitions](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/sys/attr.h>).

## Supported APIs and limits

* **`O_SEARCH` exists:** actual SDK `sys/fcntl.h` defines it as `O_EXEC|O_DIRECTORY`; `open(2)` documents search-only directory access. It may avoid requiring directory-read permission, but cannot bypass missing search permission/ACL denial. Success and suitability for subsequent operations require a separately frozen control, not a numeric-flag guess.
* **Do not adopt `O_EVTONLY` as a repair descriptor:** Apple's manual says it is intended only for change monitoring and does not prevent volume unmount. `fstat`/`fchmod` declarations do not establish this intended use as a general permission-bypass handle.
* **`fchmodat` is public since macOS10.10.** Relative leaf lookup is anchored to the parent descriptor, and `AT_SYMLINK_NOFOLLOW` acts on a symlink itself; it does **not** reject a symlink substituted during a race. It still requires ownership/authorization. Local Apple Python3.9 headers define `HAVE_FCHMODAT`/`HAVE_LCHMOD`; its `os.py` exposes capability sets. [CPython3.9.6 implementation](https://github.com/python/cpython/blob/v3.9.6/Modules/posixmodule.c#L2981-L3089) routes combined `dir_fd`/`follow_symlinks=False` to `fchmodat`, with unsupported-operation errors. This is source feasibility, not proof the actual selected interpreter accepts the combination.

[Open contract](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/share/man/man2/open.2>), [flags](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/sys/fcntl.h>), [chmod contract](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/share/man/man2/chmod.2>), [declarations](</Library/Developer/CommandLineTools/SDKs/MacOSX.sdk/usr/include/sys/stat.h>).

## Narrow conditional candidate

The [pinned Lume helper](https://github.com/trycua/cua/blob/3350f504014c85416009a90fcb339fe556ce02fc/libs/lume/src/Unattended/MacOSOfflineSetupPatcher.swift#L512-L520) adds only owner execute (`current|0100`) to **Default and Default/users** before account work. Do not copy its guessed0700 fallback. First preregister metadata-only inspection. A subsequent temporary diagnostic may add0100 only to those exact existing directories if actual metadata demonstrates that specific missing bit, suitable remaining owner permissions, no unexplained ACL/flags and stable identity. Do not widen read/write/group/other bits, clear flags/ACLs, recurse, create accounts or retry a denied operation with host privilege.

Hold both source/phase locks and operationally exclude any other cooperating writer or VM from the new disposable clone. This does not prevent interference by its owner or privileged processes. Use an anchored single leaf, recheck identity immediately before/after, then open no-follow and compare `fstat`. Parent-relative chmod is **not** an atomic expected-inode operation; an observed concurrent writer or uncoordinated phase stops the diagnostic at inspection. Prefer descriptor-bound `fchmod` once an ordinary supported descriptor exists. Restore the original mode on the verified same inode after the diagnostic, including failure; verify mode/ACL/flags and report restoration errors. Restoring mode does not restore ctime or prove the clone pristine: quarantine on inconsistency or unconfirmed restoration, detach with existing controls, and never promote it to a provisioning seed. Stored guest UID/GID correctness remains open.
