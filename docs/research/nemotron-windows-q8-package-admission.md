# Windows Q8 package producer prerequisites

`candidate_windows_sdk_receipt.py` implements the metadata prerequisite for a
package made from the exact Windows production candidate. It pins producer
`fee2177adcd7b75b488c67bea5a593ea17df65de`, its 190,779-byte protocol and separate
compiler/kernel recipe. It preserves the bounded V3 semantic runtime tag.
The original bounded packager remains unchanged and does not admit this producer.

The prerequisite rejects incomplete, failed or relabelled receipts; all four
original native/public RTF observations must be finite, positive and strictly
below one. Both complete byte-identity comparison flags, all seven lifecycle
observations and graph-input retention must be true. Every source/build/graph/
history/lifecycle command must appear in the original order with integer zero
exit, scoped background identities and complete owned-Job cleanup evidence.
Native/public histories must select the exact SDK probe/library, original public
example, fixed assets and repeat count. Lifecycle commands must select the exact
Cargo test target, feature, test name and single-threaded execution. Runtime,
recipe, protocol and recorded producer Git bytes must agree.

Six synthetic tests exercise this metadata boundary, including failed flags,
every individual RTF boundary, reordered/missing/duplicate commands, cleanup
failure, unconfirmed process membership and changed executables/SDK/audio/Cargo
arguments. They do not construct or execute an SDK/model.

`candidate_windows_payloads.py` now replays complete delivered payloads without
loading a DLL. It checks the closed delivery/output inventories,66-file SDK,
frozen model/audio identities, private PE names/imports, original bounded probe
and patches, source/compiler admission,97 retained objects and their compiler
commands, three original graph-library copies,36 complete graph vectors and
their50 bindings. Native/graph build arguments must select the pinned MSVC path
and original linker inputs. Both public executable copies, four full histories,
all actual timings and frozen probability bytes, the lifecycle reference and
seven actual test logs must agree. Compiler/linker binary identities are CI
observations; the receiver never invokes those tools.

Complete-observation replay preserves a failed timing result.
`validate_observation_metadata` requires complete functional/lifecycle evidence,
finite positive actual timings and flags/error consistent with the original
producer decision. `replay_candidate_delivery` independently recomputes the
numerical comparisons and timing decision. `validate_producer_metadata` and
`verify_candidate_delivery` remain strict package prerequisites: all four RTFs
must be below one and no producer error may be present. A successful payload
replay alone cannot enter package construction or establish package qualification.

The [actual production run](nemotron-windows-q8-candidate-results.md) completed
functional/lifecycle qualification but all four RTFs exceed one. Its unchanged
368-file delivery passes the new complete payload replay; strict package admission
rejects it before construction. The separate
[package replay receipt](../../benches/results/nemotron-diarization/windows-x86_64/2026-10-17-q8-candidate-package-replay/collection-qualification.json)
retains the actual rejection, source bindings and test evidence. No producer
receipt or timing was edited to exercise this path.

The final payload increment passes539 tool tests with seven Windows-only skips,
plus all three Pnola integration tests. Twenty-one targeted synthetic tests cover
metadata and payload corruption, exact compiler/linker selection, missing or
altered objects/libraries/full vectors, stale timing comparisons, telemetry and
ignored/multiple lifecycle executions. Synthetic timings are explicitly unit
controls; the actual failed SDK supplies the complete observation replay.

Package construction, dependency/notice provenance and fresh offline,
coexistence and supported-desktop qualification still require an actually passing
SDK. Original quality, deferred human word-time, Pnola GUI/microphone/playback/
IPC/fresh-machine, signing and release gates remain open.

The earlier metadata suite passes524 tests with seven Windows-only skips. An earlier
suite hit one macOS model-free sampler UUID rejection. Six retained owned
sampling controls (three using the exact original temporary-directory test)
and the final suite pass without changing the sampler or UUID guard. That first
failure remains an unexplained transient; the failed log and all follow-up
reports are retained under the local task cache. No Windows SDK or package pass
is inferred from these local checks.
