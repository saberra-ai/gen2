## Stack, masks and output slice

Capture the pre-projection tensor `[1,ceil(T/8),1024]`; no linear operation or neural object is necessary to inspect it.

Native V3 batches by equal state length and sends no tail-length mask into the graph. Therefore this case is a different final token domain, not evidence that an expected HF false query mask was omitted. The masks created elsewhere for heterogeneous padded state must not be mistaken for a V3 tail mask.
