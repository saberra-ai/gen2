# Windows bounded Q8 production-candidate producer

This preregistration freezes a fresh production build and the actual Gen2 public
runtime. It uses the admitted recipe in
[the candidate construction plan](nemotron-windows-q8-candidate.md), retaining the
unchanged bounded V3 semantic version and four-worker inference policy. Original
diagnostic failures, AMI quality and full desktop/release requirements remain.

`windows_q8_candidate_build.py` contains the exact original bounded SDK build
method, derived by source location without changing any build statement. Its
source verifier alone resolves to the candidate policy. The new controller
applies the three original bounded patches, independently verifies that state,
then installs the exact twentieth SGEMM patch. No diagnostic worker source,
telemetry or forced worker cap is present. The original public Rust files and
loader allowlist remain frozen and unchanged.

All compiler choices and 97 actual commands must pass admission against the
original MSVC-ABI Clang build with explicit contraction off. The original MSVC
compiler builds the native and graph probes. All 97 compiler objects are retained
with their source/command associations; SGEMM also has retained disassembly.
The source and compiled GGML maps must agree independently over 3,425 files.

Before any neural asset is acquired, retain all three actual build-only GGML
import libraries and verify their original/copy identities before every graph
process. Three fresh one/two/four-worker graph processes must preserve all 36
complete vectors, with 50 graph input/output/log bindings. Source, SDK,
compiler/linker, original and retained objects/libraries, public executable/test
bytes and earlier completed outputs are rechecked before and after subsequent
owned commands. The actual public example and test executable are retained too.

Four fresh complete 60-second processes run in native/public/public/native order.
Both pairs must match all 192,000 frozen probability bytes, original PCM,
6,000 retained rows, finalization and turns; native histories have 58 pushes.
All four RTFs must be strictly below one. No average, timing-selected retry or
new acceptance threshold is allowed. Then all seven original lifecycle tests
must execute and pass individually. A timing failure still permits the lifecycle
checks to run and remains a separately recorded failure.

Every command uses the tested Windows kill-on-close Job v2 supervisor, preserving
actual exit, owned-background membership snapshots and reaping/handle-close
evidence. The workflow runs its actual timeout/background/assignment controls
before SDK construction. Child-only Git line-ending/LFS settings and compiler/
timing environment cleanup avoid inherited build or measurement settings.

The frozen protocol binds the transitive local Python imports, recipe and native
locks, complete original public source inputs, workflow, this preregistration,
consumed compiler baselines and actual parent result manifests/payloads. Its own
bytes and inputs must also match the recorded Git commit before execution. The
workflow uploads successful or failed evidence, retained input/object/public
binary payloads and SDK; model assets and native checkout/build trees are excluded.

Success qualifies this source SDK for subsequent package admission only. Exact
package provenance, fresh offline relocation, chat/Bark/Laya coexistence,
supported-platform desktop operation, Pnola GUI/microphone/playback/IPC and
fresh-machine testing, quality, deferred human word-time review and signing/
release checks remain required. The existing packager must not infer admission
from the unchanged semantic version; its frozen historical runner/protocol
requirements do not admit this candidate automatically. Main stays unchanged.
