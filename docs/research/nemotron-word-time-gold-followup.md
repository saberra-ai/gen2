# Word-time gold follow-up: SpokenWOZ and Earnings21

Checked 2026-10-16 using the research skill. Scope: human-reviewed **word starts and ends**, associated speaker identities, and a publisher license suitable for commercial-product evaluation without requiring shipment of the source audio. No inference, native/helper execution, CI, audio playback, account creation, messages or large audio acquisition occurred. Existing frozen tools, references, protocols and prior research were unchanged.

**Result: neither candidate establishes the required gold.** SpokenWOZ has ASR-origin word annotations and a noncommercial dataset license; a procedure for human word-boundary review was not found. Earnings21 has a commercial-use license explicitly covering **transcripts/associated text**, human transcripts and speaker IDs, but the concrete reference inspected has **no populated word times**, and that text license does not establish an audio grant. A timestamp column or human transcript review is insufficient. No new evaluation fixture is selected, and N4 remains open.

## SpokenWOZ: exclude from this word-boundary gold gate

The [official project](https://spokenwoz.github.io/) links its Alibaba repository and author-hosted Hugging Face datasets and declares the **dataset CC BY-NC 4.0**. This is separate from licenses on any surrounding software. The exact [repository README at 188835d4f9948563a6b9c8ac50cd0f3ae4021ed6](https://github.com/AlibabaResearch/DAMO-ConvAI/blob/188835d4f9948563a6b9c8ac50cd0f3ae4021ed6/spokenwoz/README.md) calls each turn's `words` field the ASR transcription and shows `begin_time`, `end_time`, `channel_id` and `word_index`. These fields provide a schema, not evidence of manual boundary correction.

The [publisher paper, v7, §3.2 and Appendix D](https://arxiv.org/html/2305.13040v7#S3.SS2) specifies the manual procedure: 15 annotators label dialogue states/acts using Alibaba ASR output and audio; agent utterance text is transcribed, while user utterances intentionally retain ASR errors. Full inspection and 10% random checks assess dialogue annotation, with 97% turn-level accuracy. That does **not** report boundary-error inspection. Appendix D describes 8 kHz two-track WAVs, one user channel and one agent channel, with per-word start/end fields. This provides conversation-local speaker roles, not stable cross-dialogue person identities. No procedure establishing human review of word starts/ends was found. Equally, the inspected source does **not** establish that MFA produced these times: label them ASR-origin/unverified boundary provenance, not “MFA-aligned” by inference.

Current official access is more available than the old README's hidden-test wording suggests. The project now links these **Fixed** test repositories; public metadata was inspected, not audio:

**Disposition:** two independent missing conditions: documented human boundary review and a license grant matching the requested commercial-evaluation scope. This note makes no determination that any particular user's activity is noncommercial; the publisher's stated grant simply does not establish the requested unrestricted commercial route. Neither account creation nor a publisher permission request is necessary to continue ordinary source research, and neither was performed.

## Earnings21: stronger license/speaker provenance, no actual timed-word gold

Rev's [official repository, pinned c05ab6fd8b4b627d123c922a22a39e993dd37635](https://github.com/revdotcom/speech-datasets/tree/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21) provides public recordings, reference transcripts, speaker metadata and RTTMs. Its [dataset-specific license](https://github.com/revdotcom/speech-datasets/blob/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21/LICENSE.md) explicitly covers the transcripts and associated text files under **CC BY-SA 4.0**; do not extend that scope to the MP3s. The paper discusses public earnings-call sourcing and a fair-use precedent, which is not a publisher grant licensing every recording to Gen2. [Creative Commons' official explanation](https://creativecommons.org/licenses/by-sa/4.0/) permits commercial use of covered material with attribution/ShareAlike conditions; [legal code §3](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en#s3) attaches those conditions to sharing material/adaptations, rather than requiring publication of everything used internally. This is stronger text licensing, not a closed audio/text release-evidence contract or a legal determination about derived metrics.

The [original paper v3, §2.2–2.3](https://arxiv.org/html/2104.11348v3#S2.SS2) documents experienced human transcriptionists followed by review by senior transcriptionists. It describes verbatim text, speaker metadata and manually checked entity tags. It does **not** document human placement or correction of word boundaries. Recordings are monaural MP3, with varied sample rates; conversation-specific speaker IDs are available. Multi-speaker corporate calls are useful domain coverage, but transcript accuracy is not timing accuracy.

A concrete public pair is [4320211.mp3](https://github.com/revdotcom/speech-datasets/blob/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21/media/4320211.mp3) and [4320211.nlp](https://raw.githubusercontent.com/revdotcom/speech-datasets/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21/transcripts/nlp_references/4320211.nlp). Official GitHub metadata lists the MP3 as 13,144,562 bytes; it was **not downloaded**. The 195,519-byte NLP reference was acquired and statically parsed: 8,711 token rows, speaker IDs 0–9, **zero rows with populated start and end timestamps**. Raw SHA256 `a7d2c1e7362cc6af5317f75c855a9270c8cbbf95e04c1fe3e4834c3848e66ffb`. The [format README](https://github.com/revdotcom/speech-datasets/blob/c05ab6fd8b4b627d123c922a22a39e993dd37635/earnings21/README.md) defines `ts`/`endTs` in seconds, but that definition cannot fill empty fields. This finding is scoped to the inspected reference, not an unperformed full-corpus scan. RTTM speech spans cannot supply missing individual word bounds.

**Disposition:** potentially useful licensed transcript/speaker material, **excluded as existing human-timed word gold**. Running any forced aligner to fill its empty columns would produce a new automatic reference, not the missing human gold.

## Recent primary-source cross-check and operational next step

The September/October 2026 [FA-Bench paper v2, §2.2](https://arxiv.org/html/2609.32396v2#S2.SS2) still uses existing TIMIT/Buckeye human boundaries, rather than publishing a new freely licensed conversational word-time corpus. Its open benchmark code is not a new license for source audio or labels. No prior rejected corpus was reacquired here.

Do not run Bark against either candidate as an asserted timing-gold evaluation. The next admissible experiment needs an exact frozen audio/annotation pair **and explicit boundary-review provenance**. If creating new gold on appropriately licensed audio, preregister a small model-blind calibration selection; have a human inspect waveform/spectrogram and independently review every lexical start/end and speaker identity, retain unresolved/coarticulated boundaries and disagreements, and freeze adjudicated labels before viewing Bark timing outputs. This is proposed manual work, not evidence already obtained. Keep calibration separate from held-out acceptance; count missing/inserted/substituted words as well as boundary errors. No p95threshold is invented, and no DER criterion or N4 quality claim is weakened.
