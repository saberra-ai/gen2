# Graph CPU artifact replay and bounded return

`graph_cpu_transport.py remote` connects the prepared graph-only receivers to
the existing Linux owned-process acquisition and result-bundle transport.
`graph_cpu_transport.py local` connects the result to the existing local
quarantine algorithms. Both protocols initially have unset actual identities;
both commands reject that state before acquisition or helper execution. No
native graph/model diagnostic is dispatched by this preparation checkpoint.

The entry point uses only stdlib code before binding every native tool/reference,
the fixed receiver recipe and all transport dependencies. Conflicting pins
reject. Only then does it compile the exact original transport source, with
declared source seams, literal diagnostic-name changes and data-global identity
configuration. The historical sources stay immutable. The original protocol
bytes captured by the entry point must still match when the configured runner
reads them. Optimized Python, which would disable inherited assertions, rejects.

The Linux route keeps the original8GiB floor before every command, full archive
acquisition and bundle creation. All commands use the original bounded process
supervisor. Source preparation invokes the existing source-only worker directly
inside its outer-owned group: eight acquisitions and eleven compositions,
complete3,425-file materialization and no SDK/compiler/model execution. The
three graph-only receivers are derived, relocated and bound before network
acquisition. Their original compiler/source/PE/import-library/graph/vector/full
model-output and observer-bound checks remain required.

Actual terminal native source/run/job/archive identities must be frozen before
download. The independent feature run must have all13 named jobs successful at
the same native source. Its raw API responses are first-bound and returned in
the command proof. Local admission independently checks those feature records
against the returned bundle metadata. This prerequisite supplies feature
compatibility evidence, not native timing or production qualification.

The Linux runner creates one result-only commit and a bounded128MiB Git bundle.
The local route keeps the4GiB floor, exact artifact ZIP/digest/result/bundle/
collection identities,192MiB expansion cap and separate object-store quarantine.
It accepts only new regular blobs under the graph result root. Source refs,
index and HEAD are checked unchanged. Complete raw ZIP/path/symlink/duplicate/
expansion controls and actual tiny Git bundle mutations exercise the configured
graph receiver. The quarantine/header/namespace algorithms remain identical to
the historical receiver.

Fourteen focused controls pass, including the configured receiver's real tiny
Git bundle/quarantine cases, immutable source/AST checks, complete first-binding
and conflicting-pin mutations, actual receiver preparation before network,
native API identity mutations and same-source thirteen-job feature admission.
Fixture identities are explicitly artificial and no actual diagnostic artifact
is acquired. The final complete local suite passes683 tests in54.503 seconds,
with eight Windows-only skips (675 executed), including the collection identity
repair. Direct remote/local entry controls
reject unset identities without creating cache/output, and optimized Python
rejects before protocol use. A read-only check of the actual completed feature
run39094365701 at `0b2b7a7e` also passes the new13-job API admission function;
this verifies compatibility with that historical API record only.

`freeze_graph_cpu_transport.py` freezes both recipes. Actual native metadata is
supplied later with `--native-identity`, and actual bounded return identities
with `--return-identity`; these files are JSON data, never executable code.
Both freezing and acquisition validate the full identities and original caps.
Collection identity requires the exact member/byte/manifest fields, strict
bounded integers and a complete manifest byte count/SHA256 before consumption.
Freezing an identity does not establish a passing result: raw API records,
archive digests, semantic replay and local independent review must still agree.

The new workflow registers with an echo-only push job. Its replay job is guarded
for manual dispatch and rejects unset identities. Before native dispatch, the
remaining independent local semantic replay must also be concrete; quarantine
integrity alone is insufficient. No new artifact has been consumed or model
executed here. Absolute quality, Windows production real time, deferred human
review, physical GUI/microphone, fresh-machine, platform and signing gates stay
open. Private app transfer remains skipped and main remains unchanged.
